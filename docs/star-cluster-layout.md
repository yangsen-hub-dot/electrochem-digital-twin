# 疏散星团与实验室分区

采用用户选择的第三张“疏散星团”，替换上次的行星弧光背景。星团素材以 CSS 水平翻转，将原图右侧星团置于左侧；原始图片不改写。首页星空图层限于左侧 56% 宽度，实验室图层从右侧显示，以独立渐隐边缘分区；手机尺寸调整为左侧星空与最右侧实验室。

工作台各视图同步使用新星团图，背景主要分布在左侧。模型选择区保留原来的银河背景。实验录像、同帧预览和计算内容不叠加装饰。

`frontend/assets/star-cluster.webp` 为内置 imagegen 生成的装饰性概念素材，采用第三张候选原图；不作为天文观测数据。提示概要：稀疏疏散星团、微弱银蓝反射星云、靛蓝留白、星点集中在一侧、无密集银河星带、无文字或标志。
