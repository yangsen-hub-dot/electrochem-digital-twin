# 误差参数档案库

本目录只保存“在什么条件下，某类误差参数有何来源/范围”的档案；误差如何作用于状态由 `electrochem_sim/error_model.py` 与对应物理模块实现。更换实验时新增适用条件不同的档案，不把不同实验、枪头、液体和体积的数值混成一套通用档位。

## 分类层级

| 层级 | 含义 | 示例 |
| --- | --- | --- |
| 误差类别 | 流程中的误差来源 | `pipetting`、`tip_carryover`、`mixing` |
| 误差因子 | 类别内可单独追踪的物理效应 | `pipetting.systematic_bias`、`pipetting.repeatability` |
| 模型 | 误差如何产生并作用于状态 | 本轮共享偏差、逐次吸液波动、枪头残液质量转移、混匀后浓度不均匀衰减 |
| 参数档案 | 模型参数适用的设备/体积/液体/枪头/操作与证据 | 本目录中的 JSON 档案 |
| 档位 | 某个模型在适用范围内的误差强度 | 低/中/高；不是固定取值，范围和抽样规则需分别记录 |

## 当前档案

`copper_cell_aqueous_100_500_900ul_reference_v2.json` 是当前使用的水系参考档案，移液数据仅针对约 100、500、900 µL 的对应体积点附近。枪头残液和混匀均采用各自参数化的截断高斯先验；范围、均值和标准差是供原型运行的工程暂定设定，不是当前设备的校准值，后续可按实际枪头和混匀操作微调。这里的均值和标准差描述截断前的正态分布，截断后实际标准差会小于母体标准差。`v1` 保留为旧版范围内均匀抽样档案，便于追溯。

当前档案将移液内部拆为两个因子：

- 系统偏差：同一轮、同一体积档共享；若来源只给容差界限，界限内均匀抽取仅表达“本机未知参数”的暂定先验，不表示真实偏差服从均匀分布。
- 重复性：每次吸液分别抽取；可用来源给出的 CV 做零均值高斯近似，并拒绝会产生非正体积的抽样。

枪头残液按“排液后留在枪头内的正体积”及物料守恒计算。每档分别配置范围、先验均值和标准差；每轮从该截断高斯分布抽取一个值并在本轮排液中复用。因枪头规格尚未确认，先验参数暂作通用水系一次性枪头情景，后续需校准。已发表的一次性枪头清洗后带入洗液数据只作为量级参考，不直接当成常规铜盐溶液残液参数。

混匀不完全以一次混匀动作消除概念液体分区之间浓度差异的比例描述。每档分别配置有界范围、先验均值和标准差；每轮抽取一个截断高斯效率值并在本轮混匀动作中复用。状态模块据此更新分区浓度、均匀度和浓度离散程度。混匀不足不会阻止总体平均浓度的理论电压计算；系统另外给出分区浓度极值组合形成的局部电压情景范围。该简化模型不模拟空间位置、流场或电极附近浓度，也不把情景范围当作实测值。公开的 96 孔板循环次数/模型结果不是当前半电池容器的实测效率，因此这些先验参数需按容器、混匀方式和循环数校准。

## 新增档案时的命名和必填项

建议文件名：`{实验或液体类别}_{设备/枪头}_{目标体积范围}_reference_vN.json`。每份档案记录唯一 `profile_id`、适用条件、误差因子、模型、每档的上下限、抽样规则、数据类型（实测/厂家规格/模型推断/工程暂定）、来源链接、不可外推条件和当前是否可用于仿真。证据不够时明确写 `insufficient_evidence`，不要用零代替未知，也不要把文献参考区间直接激活为当前设备参数。

实验配置通过 `profile_file` 选择档案，再为有适用数据的误差因子选择模型和档位。档案不应覆盖实验条件，也不应把虚拟电压误差与操作误差混在一起。
